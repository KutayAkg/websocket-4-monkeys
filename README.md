# 🐒 WebSocket for Monkeys

Merhaba! Bu repo içerisinde bir maymuna anlatırmış gibi **WebSocket** nedir, nasıl kullanılır onu öğreniyoruz. 🍌

Anlatım için `WebSocket_Nedir.md` dosyasına bakabilirsin.

### 🚀 Hızlı Başlat
1. `npm install ws`
2. `node server.js`
3. `index.html` dosyasını 2 farklı sekmede aç ve chat yapmaya başla!
